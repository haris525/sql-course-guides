# SQL from Zero: written guides

Written guides for the SQL from Zero course on YouTube. Each guide matches its video
step by step: every command and SQL line exactly as typed, the real output, and pictures
from the video. Keep one open next to the video, or follow it on its own.

The course is for complete beginners. You don't need to have used a database or opened a
terminal before. It uses DuckDB, a free database that needs no server or password.
